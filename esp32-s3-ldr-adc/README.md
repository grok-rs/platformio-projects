# ESP32-S3: вимірювання освітленості — фоторезистор і АЦП

Модуль 1.6, домашнє завдання. Фоторезистор (LDR) і резистор 10 кОм утворюють подільник напруги.
Кожні 100 мс ESP32-S3 вимірює напругу в його середній точці двома способами й порівнює:

| Що | Як отримуємо |
|---|---|
| `RAW` | `analogRead(4)`: «сире» число АЦП, 0…4095 |
| `U_calc` | за формулою `RAW / 4095 · 3100 мВ` |
| `U_meas` | `analogReadMilliVolts(4)`: калібровані мВ |
| `error` | `(U_calc − U_meas) / U_meas · 100 %` |

```bash
cd esp32-s3-ldr-adc/cpp && pio run -t upload && pio device monitor   # C++: src/main.cpp
cd esp32-s3-ldr-adc/rust && cargo run --release                      # Rust: src/main.rs
```

Інтерактивні сторінки: [АЦП і світло](https://grok-rs.github.io/platformio-projects/adc-light/),
[Люксметр на ESP32-S3](https://grok-rs.github.io/platformio-projects/ldr-lab/).

## Схема

![Принципова схема](docs/schematic.png)

```
 3V3 ──[ LDR ]──┬──[ 10 кОм ]── GND
                │
              GPIO4  (ADC1_CH3)
```

`U_out = 3.3 В · 10 кОм / (R_LDR + 10 кОм)`. LDR зверху — тому більше світла дає *більшу* напругу:

| Освітлення | R_LDR (≈ GL5528) | U_out | RAW |
|---|---|---|---|
| долоня / ніч, 0.1 лк | ~380 кОм | ~85 мВ | ~113 |
| сутінки, 10 лк | ~15 кОм | 1.32 В | 1744 |
| кімната, 100 лк | ~3 кОм | 2.54 В | 3355 |
| сонце, 100 000 лк | ~25 Ом | 3.29 В | **4095** (стеля) |

GPIO4 належить **ADC1** (GPIO1…10) — працює завжди. ADC2 (GPIO11…20) ділить апаратуру з Wi-Fi.
Не strapping (0, 3, 45, 46) і не USB (19, 20). Понад 3.3 В на пін не подавати.

## Як це працює

Неблокуючий таймер на 100 мс, два окремі виміри і формула з умови:

```cpp
int raw = analogRead(LDR_PIN);                    // «сире» число АЦП
uint32_t measMv = analogReadMilliVolts(LDR_PIN);  // калібровані мВ (eFuse)
float calcMv = raw / ADC_MAX * UREF_MV;           // формула з умови
```

```
RAW: 1744  U_calc: 1320.2 mV  U_meas: 1300 mV  error: +1.56 %
RAW:  113  U_calc:   85.5 mV  U_meas:  111 mV  error: -22.97 %
```

(числа — ілюстрація формату)

- **`3100`, а не `3300`.** З ослабленням 11 дБ АЦП ESP32-S3 вимірює 0…3100 мВ; усе вище — 4095.
- **`analogReadMilliVolts()`** (з великою **V**; в умові помилково `Millivolts`) враховує заводське
  калібрування з eFuse, `analogRead()` — ні. Це два окремі перетворення, тож у `error` є й шум АЦП.
- **`U_meas = 0`** — похибка не визначена, друкується `n/a`. Біля нуля відносна похибка «вибухає»:
  3 мВ різниці при 10 мВ — це вже 30 %.

## Звідки похибка

1. **Номінальний `U_ref`.** Реальна «стеля» конкретного чипа відрізняється від 3100 мВ на кілька %.
2. **Зсув нуля.** Перші десятки мВ АЦП може показувати як 0.
3. **Нелінійність** біля 0 і 3.1 В — калібрування її враховує, пряма формула — ні.
4. **Шум** — допомагає усереднення.

На платі з каліброваним АЦП чекайте похибку в кілька відсотків; «−» означає, що формула занижує.

## Перевірка

Долоня → `RAW` падає; ліхтарик → росте, дуже яскраво → `RAW 4095`, `U_calc 3100.0`. Завжди `0` —
перемичка GPIO4 не в ряду подільника; завжди `4095` — немає 10 кОм до GND; на світлі число **падає** —
LDR і 10 кОм переплутані місцями.

## Контрольні питання

2. LDR = 5 кОм, R2 = 10 кОм, 3.3 В: яка напруга на GPIO4 і яке RAW?
3. Чим `analogRead()` відрізняється від `analogReadMilliVolts()`?
4. Чому для датчиків з Wi-Fi беремо ADC1?
