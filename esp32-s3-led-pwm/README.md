# ESP32-S3: яскравість світлодіода через ШІМ (PWM)

Урок за викладачем (проєкт `Blink_Correct`): світлодіод на GPIO15 світить не на повну, а на **25 %** —
апаратний ШІМ-блок LEDC, 5000 Гц, 8 біт, `ledcWrite(0, 64)`. `loop()` порожній.

```bash
cd esp32-s3-led-pwm/cpp && pio run -t upload && pio device monitor   # C++: src/main.cpp
cd esp32-s3-led-pwm/rust && cargo run --release                      # Rust: src/main.rs
```

## Схема

![Принципова схема](docs/schematic.png)

![Монтаж на макетній платі](docs/breadboard.png)

```
GPIO15 ── 220 Ом ── LED ── GND (пін G біля USB-C; поруч 5V — не переплутати)
   └── CH1 логічного аналізатора, GND аналізатора ── G
```

На макетці: GPIO15 → ряд 25, резистор — ряди 25…29, довга ніжка LED — ряд 29, коротка — ряд 30 → шина «−».
Аналізатор: **CH1 → `f25`**, **GND → `a2`**.

## Як це працює

Вивід уміє лише 0 В або 3.3 В. ШІМ дуже швидко вмикає й вимикає його, а око бачить **середню**
яскравість — частку періоду в HIGH (коефіцієнт заповнення, duty):

```
duty 25 %  (ledcWrite 64)    ▔|____|▔|____|▔|____     світить слабко
duty 50 %  (ledcWrite 128)   ▔▔|__|▔▔|__|▔▔|__
duty 100 % (ledcWrite 255)   ▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔     майже як digitalWrite(HIGH)
           |<-- 200 мкс -->|  період = 1 / 5000 Гц
```

Три кроки LEDC (канал генерує сигнал, пін лише «підключається» до каналу):

```cpp
ledcSetup(ledChannel, 5000, 8);       // канал 0: 5000 Гц, 8 біт → значення 0…255
ledcAttachPin(LED_OUT, ledChannel);   // вивести канал 0 на GPIO15
ledcWrite(ledChannel, 64);            // 64 / 256 = 25 %
```

Розрядність 8 біт → 2⁸ = 256 рівнів (`0…255`). Більше біт — плавніше, але менша максимальна частота:
`частота × 2^біт ≤ 80 МГц`. `ledcSetup`/`ledcAttachPin` — API ядра 2.x (`espressif32@^7.1.0`); у core 3.x
те саме — `ledcAttach(LED_OUT, 5000, 8); ledcWrite(LED_OUT, 64);`. У Rust ті самі три кроки:
`ledc.timer(...).configure(...)` → `ledc.channel(Channel0, GPIO15)` → `set_duty(25)` (esp-hal бере відсотки).

## Перевірка

1. LED світить помітно слабше, ніж із `digitalWrite(HIGH)`. Замініть `64` на `0`, `16`, `128`, `255`:
   між 128 і 255 різниця на око менша, ніж між 16 і 64 — око сприймає яскравість нелінійно.
2. Логічний аналізатор (PulseView, ≥ 1 МГц): на CH1 — період 200 мкс, HIGH 50 мкс.

## Питання для самоперевірки

1. **50 % і 75 % при 8 бітах? При 10?** 128 і 192; при 10 бітах — 512 і 768 (з 1024).
2. **Частота 5 Гц?** Період 200 мс — око встигає за кожним імпульсом, LED мигає замість того, щоб світити тьмяно.
3. **Плавне наростання й згасання:**
   ```cpp
   void loop() {
     for (int d = 0; d <= 255; d++) { ledcWrite(ledChannel, d); delay(5); }
     for (int d = 255; d >= 0; d--) { ledcWrite(ledChannel, d); delay(5); }
   }
   ```
