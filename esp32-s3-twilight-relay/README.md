# ESP32-S3: сутінковий перемикач — LDR, транзисторний ключ і модуль реле

Міні-проєкт 1 (урок 18, «підключення сенсора і актуатора, відладчик»). Фоторезистор у подільнику
напруги дає ESP32-S3 число АЦП. Програма порівнює його з двома порогами і через транзистор BC547B
керує 5-вольтовим модулем реле. Реле вмикає навантаження (світлодіод або LED-стрічку).

| АЦП (GPIO4)               | Рішення                 | GPIO2          | Реле |
|---------------------------|-------------------------|----------------|------|
| `< 500` (темно)           | `relayOn = true`        | HIGH, 3,3 В    | ON   |
| `> 600` (світло)          | `relayOn = false`       | LOW, 0 В       | OFF  |
| `500…600`                 | нічого не змінюємо      | як було        | як було |

Плата — **YD-ESP32-S3** (VCC-GND Studio, клон ESP32-S3-DevKitC-1, N16R8).

```bash
cd esp32-s3-twilight-relay/cpp
pio run -t upload          # зібрати та прошити
pio device monitor         # 115200: рядок «adc=… relay=…» кожні 100 мс
```

### Інтерактивна сторінка

[**Сутінковий перемикач**](https://grok-rs.github.io/platformio-projects/twilight-relay/) — ця схема
в анімації: макетка з модулем живлення Type-C і модулем реле, принципова схема з живими напругами,
струм і електрони на дротах, клік по будь-якій деталі показує напруги на її виводах. Є досліди з
помилками (GPIO напряму в IN, без спільної землі, без гістерезису, лампа світить на LDR, без діода),
петля гістерезису і цей самий код з підсвіткою гілки.

| R1    | Фоторезистор GL5528 / GL5516                      | 1     | полярності немає                                |
| R2–R4 | Резистор 10 кОм                                   | 3     | коричнева-чорна-помаранчева                     |

| —     | Макетна плата 830 точок, дроти «тато–тато» ≈12, «мама–тато» 3 |  | «мама–тато» — до гребінки модуля реле |

## 2. Схема

Намальована схема з живими напругами — на [інтерактивній сторінці](https://grok-rs.github.io/platformio-projects/twilight-relay/#schem).
З'єднання по вузлах:

```
3V3 ─── R1 (LDR) ───┬─── R2 10 кОм ─── GND
                    └─── GPIO4 (ADC1_CH3)

GPIO2 ─── R3 10 кОм ─── база VT1 (BC547B)
+5 В ──── R4 10 кОм ───┬─── колектор VT1
                       └─── IN модуля U1
емітер VT1 ─── GND

+5 В ─── VCC U1          GND ─── GND U1
+5 В ─── COM U1          NO U1 ─── R5 220 Ом ─── LED1 (анод → катод) ─── GND
                         NC U1 — вільний
```

Усі «+3,3 В», «+5 В» і «GND» на схемі — це мітки проводів, а не окремі джерела. Усі «GND» — один
спільний провід (ESP32, модуль живлення, модуль реле).

### Чому між GPIO і модулем реле стоїть транзистор

Усередині модуля стоїть PNP-транзистор: емітер на VCC = 5 В, база через 1 кОм виходить на IN.
PNP відкривається, коли IN нижче приблизно `5 − 0,7 = 4,3 В`. Тому 3,3 В з GPIO для модуля — теж
LOW: якщо з'єднати GPIO з IN напряму, реле **ніколи не вимкнеться**, а ≈1 мА тектиме з 5-вольтової
частини в пін ESP32.

VT1 узгоджує рівні. Сигнал інвертується двічі, тож HIGH на GPIO2 = реле ON, як вимагає умова:

| GPIO2      | VT1        | IN (R4 до 5 В) | PNP модуля | Реле |
|------------|------------|----------------|------------|------|
| LOW, 0 В   | закритий   | 5 В            | закритий   | OFF  |
| HIGH, 3,3 В| відкритий  | ≈0,09 В        | відкритий  | ON   |

Розрахунок для HIGH: струм бази `(3,3 − 0,7) / 10 кОм ≈ 0,26 мА`. Колектор приймає `0,49 мА` з R4 і
`≈4,2 мА` з бази PNP. Примусове β ≈ 18 ≪ h_FE 200…450, тож VT1 гарантовано в насиченні.
Котушка реле бере ≈70 мА — у 3,5 раза більше за рекомендовані 20 мА на пін, тому її живить
транзистор модуля, а не ESP32.

## 3. Живлення

| Що                | Звідки                                   | Навіщо так |
|-------------------|------------------------------------------|------------|
| ESP32             | USB від ПК (прошивка, Serial)            | |
| Верхня шина 3,3 В | пін **3V3** плати                        | на GPIO4 ніколи не буде напруги, коли ESP32 вимкнена |
| Нижня шина 5 В    | модуль живлення U2, перемичка **5V**     | котушка й лампа не навантажують ESP32 |

- **Перемички U2: верхня знята (OFF), нижня на 5V.** Верхня шина з'єднана з піном 3V3 плати, тож
  верхня перемичка на 5V подасть **5 В у пін 3V3 і спалить ESP32**.
- **ESP32 від U2 замість USB:** дріт з нижньої шини +5 В у пін **5V** плати (в обхід макетки).
  На YD-ESP32-S3 між USB і піном 5V стоїть діод (перемичка IN-OUT розімкнена), тож USB для прошивки
  можна лишити. Ніколи: 5 В на пін 3V3 або 3,3 В на пін 5V.
- Споживачі на шині 5 В підключені паралельно: напруга в усіх однакова, струми додаються
  (ESP32 ~60 мА + реле ~80 мА + LED ~9 мА ≈ 150 мА).

## 4. Монтаж на макетній платі

Розкладка та сама, що на інтерактивній сторінці (плата в стовпцях 1–22, USB ліворуч):

| Що            | Звідки                          | Куди                     | Дріт |
|---------------|---------------------------------|--------------------------|------|
| U2            | правий край, штирі в усі 4 шини | перемички: верх OFF, низ 5V | |
| GND           | J1 стовп. 1, ряд a              | верхня шина −            | чорний |
| GND           | J3 стовп. 1, ряд j              | нижня шина −             | чорний |
| 3V3           | J1 стовп. 22, ряд a             | верхня шина +            | помаранчевий |
| LDR (R1)      | 25c                             | 28c                      | + помаранчевий з верхньої + у 25a |
| R2 10 кОм     | 28e                             | 33e                      | + чорний з 33a на верхню − |
| GPIO4         | J1 стовп. 19, ряд a             | 28a                      | жовтий |
| GPIO2         | J3 стовп. 18, ряд j             | 26j                      | зелений |
| R3 10 кОм     | 26f                             | 31f                      | |
| VT1 BC547B    | E 30h · B 31h · C 32h           | пласкою стороною до центру | + чорний з 30j на нижню − |
| R4 10 кОм     | 32f                             | 37f                      | + червоний з 37j на нижню + (5 В!) |
| U1 IN / VCC / GND | 32j / нижня + / нижня −     | гребінка модуля          | фіолетовий / червоний / чорний («мама–тато») |
| COM           | нижня шина +                    | клема COM                | червоний |
| NO            | клема NO                        | 42j                      | білий |
| R5 220 Ом     | 42h                             | 46h                      | |
| LED1          | анод 46f                        | катод 47f                | + чорний з 47j на нижню − |

**Перед першим увімкненням:** без кабелів продзвоніть «+» і «−» кожної пари шин (КЗ немає),
перевірте перемички U2, увімкніть U2 (на нижній шині 4,8…5,2 В, червоний LED модуля світиться),
і лише тоді підключайте ESP32.

## 5. Код

`cpp/src/main.cpp` робить три кроки кожні 100 мс:

1. `analogRead(4)` — число 0…4095 (12 біт, ослаблення 11 дБ, ≈0…3,1 В).
2. Пороги з гістерезисом: `< kThresholdDark` → `relayOn = true`, `> kThresholdLight` → `false`,
   між ними — нічого не змінюється.
3. `digitalWrite(2, relayOn)` і рядок у Serial.

```
18:24:01.100 -> adc= 692 relay=OFF        кімната
18:24:05.300 -> adc= 351 relay=ON         LDR накрили долонею
18:24:06.900 -> adc= 588 relay=ON         між порогами (руку прибирають): стан не змінюється
18:24:07.000 -> adc= 689 relay=OFF        знову світло
```

**Пороги** підбирайте на своїй макетці: стежте за `adc` у Serial у потрібних сутінках.
У `cpp/src/main.cpp` (і `rust/src/main.rs`) вони вже відкалібровані за записом із реальної макетки: кімната ≈ 690,
LDR під долонею ≈ 350, тож `kThresholdDark = 500`, `kThresholdLight = 600`. На інтерактивній
сторінці лишилися 1000 / 1500: там модель фоторезистора, а не ваш LDR і ваша кімната.
Проміжок між `kThresholdDark` і `kThresholdLight` має бути більшим за шум АЦП (±10…20) і за те,
наскільки лампа підсвічує LDR. Інакше реле клацатиме. Найкраще — сховати LDR від лампи.

## 6. Відладчик

ESP32-S3 має вбудований USB-JTAG, окремий програматор не потрібен. У `cpp/platformio.ini` вже є
`debug_tool = esp-builtin` і `debug_init_break = tbreak setup`. Далі **F5** / *Run and Debug →
PIO Debug*, кабель — у роз'єм **USB**. Для змінних без оптимізацій додайте `build_type = debug`.

- Точка зупинки на `if (adc < kThresholdDark)`, у *Watch* — `adc` і `relayOn`.
- Умовна точка зупинки `adc < 1000` зупинить програму саме в момент «стемніло».
- Точка зупинки зупиняє код, а не фізику: поки процесор стоїть, GPIO2 тримає рівень, і реле
  лишається, як було.

## 7. Якщо щось не працює

| Симптом                                  | Ймовірна причина                                      |
|------------------------------------------|-------------------------------------------------------|
| Реле не вимикається ніколи               | GPIO напряму в IN, або R4 іде на 3,3 В замість 5 В    |
| Реле мовчить, зелений LED модуля не світиться | немає спільної GND; VT1 повернутий (E і C); немає 5 В на нижній шині |
| Зелений світиться, лампа ні              | навантаження на NC замість NO; COM не затиснутий; LED1 навпаки |
| Реле клацає без зупинки                  | вузький проміжок між порогами; лампа світить на LDR   |
| `adc` завжди 4095                        | R2 не з'єднаний з GND                                 |
| `adc` близько 0                          | LDR не отримує 3,3 В                                  |
| ESP32 перезавантажується, коли клацає реле | просідання живлення: реле від U2, 100 мкФ на шину 5 В |

## Rust-версія

Тека [`rust/`](rust/) — той самий перемикач на **esp-hal** + **Embassy**; рядок у Serial такий самий
(`adc= 692 relay=OFF`). Встановлення тулчейну — у [кореневому README](../README.md#rust).

```bash
source ~/export-esp.sh                     # тулчейн Xtensa від espup, раз на термінал
cd esp32-s3-twilight-relay/rust
cargo run --release                        # зібрати, прошити, відкрити монітор
cargo +stable host-test -p twilight-relay  # тести гістерезису на ПК, без плати
```

| | C++ (Arduino) | Rust (esp-hal + Embassy) |
|---|---|---|
| АЦП | `analogReadResolution(12)`, `analogSetPinAttenuation(4, ADC_11db)`, `analogRead(4)` | `AdcConfig::enable_pin_with_cal::<_, AdcCalBasic<ADC1>>(GPIO4, _11dB)`, `adc.read_blocking(&mut ldr)`; GPIO з ADC2 не збереться |
| Гістерезис | глобальний `relayOn` + `if / else if` у `loop()` | `Hysteresis` у `src/lib.rs`: пороги перевіряються під час компіляції (`dark < light`), тести на ПК |
| Період 100 мс | `if (millis() - lastReadAt < kPeriodMs) return; lastReadAt += kPeriodMs;` | `Ticker::every(100 мс)` — так само без «повзання», а ядро між тіками спить |
| Реле | `digitalWrite(2, relayOn ? HIGH : LOW)` | `relay.set_level(relay_on.into())` |
| Відладчик | `debug_tool = esp-builtin`, F5 | `probe-rs` через той самий вбудований USB-JTAG; символи вже в ELF (`debug = 2` у release) |
