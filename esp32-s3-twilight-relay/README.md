# ESP32-S3: сутінковий перемикач — LDR, транзисторний ключ і модуль реле

Міні-проєкт 1 (урок 18). Фоторезистор у подільнику дає число АЦП на **GPIO4**. Кожні 100 мс програма
порівнює його з двома порогами (гістерезис) і через транзистор **BC547B** на **GPIO2** керує 5-вольтовим
модулем реле, яке вмикає «лампу» (LED). Анімована схема, досліди з помилками й таблиця монтажу —
на [інтерактивній сторінці](https://grok-rs.github.io/platformio-projects/twilight-relay/).

| АЦП (GPIO4)     | Рішення             | GPIO2 | Реле |
|-----------------|---------------------|-------|------|
| `< 500` (темно) | `relayOn = true`    | HIGH  | ON   |
| `> 600` (світло)| `relayOn = false`   | LOW   | OFF  |
| `500…600`       | нічого не змінюємо  | як було | як було |

```bash
cd esp32-s3-twilight-relay/cpp && pio run -t upload && pio device monitor   # C++: src/main.cpp
cd esp32-s3-twilight-relay/rust && cargo run --release                      # Rust: src/main.rs
```

## Схема

Деталі: LDR GL5528, 3 × 10 кОм, 220 Ом, BC547B (2N2222 теж підійде, але цоколівка E-B-C), LED,
модуль реле 5 В «low level trigger» (на реле напис **05VDC**), модуль живлення макетки (MB-102 / USB-C).

```
3V3 ─── R1 (LDR) ───┬─── R2 10 кОм ─── GND
                    └─── GPIO4 (ADC1_CH3)

GPIO2 ─── R3 10 кОм ─── база VT1 (BC547B)
+5 В ──── R4 10 кОм ───┬─── колектор VT1
                       └─── IN модуля реле
емітер VT1 ─── GND

+5 В ─── VCC реле        GND ─── GND реле
+5 В ─── COM реле        NO ─── R5 220 Ом ─── LED1 (анод → катод) ─── GND      NC — вільний
```

Усі «GND» — один **спільний** провід (ESP32, модуль живлення, модуль реле).

**Чому транзистор, а не GPIO прямо в IN.** У модулі стоїть PNP: емітер на 5 В, база через 1 кОм на IN.
Він відкривається, коли IN нижче ≈ 5 − 0,7 = 4,3 В, тож 3,3 В з GPIO для модуля — теж LOW: реле **ніколи
не вимкнеться**, а ≈ 1 мА тектиме з 5-вольтової частини в пін ESP32. VT1 інвертує сигнал, модуль —
ще раз, тому HIGH на GPIO2 = реле ON:

| GPIO2 | VT1 | IN (R4 до 5 В) | Реле |
|---|---|---|---|
| LOW, 0 В | закритий | 5 В | OFF |
| HIGH, 3,3 В | відкритий | ≈ 0,09 В | ON |

**Розрахунок для HIGH.** I<sub>Б</sub> = (3,3 − 0,7) / 10 кОм ≈ **0,26 мА**. Колектор приймає 0,49 мА з R4 і ≈ 4,2 мА
з бази PNP модуля: примусове β ≈ 18 ≪ h<sub>FE</sub> 200…450 — VT1 гарантовано в насиченні. Котушка реле
бере ≈ 70 мА (у 3,5 раза більше за 20 мА на пін), тому її живить транзистор модуля, а не ESP32.

## Живлення — безпека

* Верхня шина 3,3 В — від піна **3V3** плати; нижня шина 5 В — від модуля живлення (перемичка **5V**).
* **Верхня перемичка модуля живлення знята (OFF).** Інакше 5 В потрапить у пін 3V3 і спалить ESP32.
* Ніколи: 5 В на пін 3V3, 3,3 В на пін 5V, 5 В у будь-який GPIO.
* Перед першим увімкненням продзвоніть «+» і «−» кожної шини (КЗ немає), перевірте перемички,
  на нижній шині має бути 4,8…5,2 В — і лише тоді підключайте ESP32.

## Як це працює

Кожні 100 мс: `analogRead` (12 біт, 11 дБ, ≈ 0…3,1 В) → пороги з гістерезисом → `digitalWrite` і рядок
у Serial. `last += PERIOD_MS`, а не `last = millis()`, тож крок не «повзе»:

```cpp
if (adc < DARK) {
  relayOn = true;   // темно
} else if (adc > LIGHT) {
  relayOn = false;  // світло
}                   // між порогами — нічого не міняємо
```

```
adc= 692 relay=OFF        кімната
adc= 351 relay=ON         LDR накрили долонею
adc= 588 relay=ON         між порогами: стан не змінюється
adc= 689 relay=OFF        знову світло
```

**Пороги** підбирайте за `adc` у Serial у своїх сутінках (тут: кімната ≈ 690, долоня ≈ 350 → 500 / 600;
на інтерактивній сторінці 1000 / 1500 — там модель, а не ваш LDR). Проміжок має бути більшим за шум
АЦП (±10…20) і за те, наскільки лампа підсвічує LDR, — інакше реле клацатиме. Сховайте LDR від лампи.

## Відладчик

ESP32-S3 має вбудований USB-JTAG: у `platformio.ini` вже є `debug_tool = esp-builtin` і
`debug_init_break = tbreak setup`. **F5** / *Run and Debug → PIO Debug*, кабель — у роз'єм **USB**.
Для змінних без оптимізацій додайте `build_type = debug`. У Rust — `probe-rs` через той самий USB-JTAG.

* Точка зупинки на `if (adc < DARK)`, у *Watch* — `adc` і `relayOn`; умовна `adc < 1000` — момент «стемніло».
* Точка зупинки зупиняє код, а не фізику: GPIO2 тримає рівень, реле лишається, як було.

## Якщо щось не працює

| Симптом | Ймовірна причина |
|---|---|
| Реле не вимикається ніколи | GPIO напряму в IN, або R4 на 3,3 В замість 5 В |
| Реле мовчить, зелений LED модуля темний | немає спільної GND; VT1 повернутий; немає 5 В на нижній шині |
| Зелений світиться, лампа ні | навантаження на NC замість NO; COM не затиснутий; LED навпаки |
| Реле клацає без зупинки | вузький проміжок між порогами; лампа світить на LDR |
| `adc` завжди 4095 / близько 0 | R2 не з'єднаний з GND / LDR не отримує 3,3 В |
| ESP32 перезавантажується, коли клацає реле | просідання живлення: реле від модуля живлення, 100 мкФ на шину 5 В |
