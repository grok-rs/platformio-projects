Датчик + актуатор: сутінковий перемикач

Фоторезистор → АЦП → гістерезис → транзисторний ключ BC547B → модуль реле 5 В → лампа. Модуль живлення Type-C на макетці.

Міні-проєкт

Сутінковий перемикач

Жива макетка й схема з анімацією електронів, пастка «3,3 В → модуль 5 В», петля гістерезису й код, деталі з попередніх уроків, правила креслення, збирання крок за кроком, відладчик і тест.
